# FYP2 Project - Final Instructions

## Quick Start (Recommended)

1. **Run the complete setup**: Double-click `COMPLETE_SETUP.bat`
   - This will download and set up all required tools (Java, Maven, Node.js)
   - Creates a portable environment in the `tools` folder
   - Generates `RUN_FYP2.bat` for running the application

2. **Run the application**: Double-click `RUN_FYP2.bat`
   - Tests the Java application first
   - Sets up and runs the Node.js/React application
   - Application will be available at http://localhost:3001

## Alternative Methods

### Method 1: Simple Run (if Node.js is already installed)
- Double-click `SIMPLE_RUN.bat`
- This will only run the Node.js/React application

### Method 2: Manual Installation
1. Install Java JDK 11 from: https://www.oracle.com/java/technologies/javase/jdk11-archive-downloads.html
2. Install Maven 3.9.6 from: https://maven.apache.org/download.cgi
3. Install Node.js LTS from: https://nodejs.org/
4. Run `run_application.bat`

### Method 3: Portable Setup
1. Run `PORTABLE_SETUP.bat` to set up portable tools
2. Run `RUN_PORTABLE.bat` to start the application

## What Each Script Does

### COMPLETE_SETUP.bat
- Downloads OpenJDK 11, Maven 3.9.6, and Node.js LTS
- Sets up portable versions in the `tools` folder
- Creates `RUN_FYP2.bat` for running the application
- **Use this if you want everything automated**

### RUN_FYP2.bat (Generated by COMPLETE_SETUP.bat)
- Tests the Java application (Pakistan Rainfall Data Fetcher)
- Installs Node.js dependencies
- Starts the full React/Node.js application
- **Use this to run the complete application**

### SIMPLE_RUN.bat
- Only runs the Node.js/React application
- Requires Node.js to be already installed
- **Use this if you only want the web application**

### run_application.bat
- Builds Java application with Maven
- Installs Node.js dependencies
- Starts the development server
- **Use this if you have all tools installed**

## Application Components

### 1. Java Application (Pakistan Rainfall Data Fetcher)
- **Purpose**: Fetches rainfall data using NASA POWER API
- **Features**: 
  - Search any location worldwide
  - Get rainfall data for past 7 days
  - Detailed statistics and analysis
- **JAR File**: `target/pakistan-rainfall-1.0.0.jar`
- **Run Command**: `java -jar target/pakistan-rainfall-1.0.0.jar`

### 2. Node.js/React Application (Sentinel Weather System)
- **Purpose**: Weather and flood risk assessment system
- **Features**:
  - User authentication and registration
  - Real-time weather data
  - Flood risk assessment
  - Community features
  - Emergency contacts
  - Risk visualization
- **Frontend**: React app at http://localhost:3001
- **Backend**: Express.js API at http://localhost:3000

## Troubleshooting

### Common Issues

1. **"java is not recognized"**
   - Solution: Run `COMPLETE_SETUP.bat` to install portable Java

2. **"mvn is not recognized"**
   - Solution: Run `COMPLETE_SETUP.bat` to install portable Maven

3. **"node is not recognized"**
   - Solution: Run `COMPLETE_SETUP.bat` to install portable Node.js

4. **"npm is not recognized"**
   - Solution: Node.js installation includes npm, reinstall Node.js

5. **Build failures**
   - Check internet connection (required for downloading dependencies)
   - Try running as administrator
   - Use `COMPLETE_SETUP.bat` for portable setup

6. **Port already in use**
   - Close other applications using ports 3000 or 3001
   - Restart the application

### Manual Commands

If you prefer to run commands manually:

```cmd
# Build Java application
mvn clean compile

# Run Java application
java -jar target/pakistan-rainfall-1.0.0.jar

# Install Node.js dependencies
cd js
npm install
cd client
npm install
cd ..

# Run Node.js application
cd js
npm run dev
```

## Support

If you encounter issues:
1. Try `COMPLETE_SETUP.bat` first (most comprehensive)
2. Check internet connection
3. Run as administrator if needed
4. Check that ports 3000 and 3001 are not in use
5. Restart your computer after installing tools

## Final Notes

- The `COMPLETE_SETUP.bat` script is the most reliable way to get everything working
- It creates a portable environment that doesn't require system-wide installations
- The generated `RUN_FYP2.bat` script will test both applications
